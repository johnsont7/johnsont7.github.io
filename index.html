Native Nursery Management System

To view the project, click here.

I started this project because the Nursery my supervisor ran had no documentation system in place and we ran into a problem when we planned to collaborate with another department but did not have as many plants as we thought causing the plans to not come to fruition. I worked with my supervisor to create a an idea of what a documentation system in the form of a website would look like and started development the next week. I chose to use flask to create the website as a reccomendation from one of my professors at Berea. My role at the time was a groundskeeping role, so I worked on this project during the downtime of my work hours, which was common during the winter. It never ended up being deployed because my supervisor and I both left groundskeeping. Although the project was never deployed, I am glad that I developed it because it served as a great learning experience for me and it was my introduction to web development.
